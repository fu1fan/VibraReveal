# 02-platform · 运行平台环境

本目录归档 VibraReveal 的运行平台：RK3588 板级环境、系统镜像与运行时版本、GPU/NPU 运行时配置，以及 macOS 侧工具链与依赖记录。

## 子模块

系统源码与构建不在本仓库维护，通过 Git 子模块接入独立仓库 [RK3588-OV9281](https://cnb.cool/fu1fan/RK3588-OV9281)，便于在本仓库内核对 BSP、驱动与镜像版本。

| 子模块                                       | 内容                                                                                 | 跟踪分支 | 当前提交                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------ | -------- | ------------------------------ |
| [RK3588-OV9281](RK3588-OV9281/)              | ELF2/RK3588 板级支持、Buildroot、Linux 内核与设备树、OV9281 驱动、GPU/NPU 运行时      | `main`   | `6376f0e`（`system-v0.1.0-vulkan.1` 之后 2 个提交） |

## 用法

首次克隆时连同子模块一起拉取：

```bash
git clone --recurse-submodules <本仓库地址>
```

已克隆的仓库初始化子模块：

```bash
git submodule update --init --recursive
```

将子模块更新到上游 `main` 最新提交：

```bash
git submodule update --remote 02-platform/RK3588-OV9281
```

## 边界

系统源码、构建配置、镜像发布与板级验收均在上游仓库进行，本仓库不修改子模块内容；平台环境与版本对应关系、已知问题记录在本目录。
