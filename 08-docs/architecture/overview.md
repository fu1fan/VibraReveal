# 系统架构概览

> 更新于 2026-11-01：本文区分当前实现与后续规划。触屏操作见 [主程序指南](../../03-apps/rk3588/TOUCH_APP.md)，实测边界见 [板端记录](../validation/rk3588-touch-2026-11-01.md)。

## 1. 数据流

```text
          OV9281 global-shutter camera
             RAW10 · up to 120 FPS
                       │ MIPI CSI-2
                       ▼
     ┌──────────────────────────────────────┐
     │ RK3588 · Linux edge device           │
     │                                      │
     │ V4L2 capture / frame timestamps      │
     │ Vulkan compute / motion pre-analysis │
     │ RKNN prompted object segmentation    │
     │ Qt/QML touch UI / exposure / FPS     │
     │ bounded DDR / lossless VRI recording │
     └──────────────────┬───────────────────┘
                        │ USB 3 custom Bulk (VRI1)
                        │ RAW frames + timestamps + metadata
                        ▼
     ┌──────────────────────────────────────┐
     │ MacBook · Apple Silicon              │
     │ Metal motion magnification           │
     │ phase spectrum / archive reader / CLI│
     └──────────────────────────────────────┘
```

本机录像写入 eMMC，逐帧 Bitshuffle + LZ4 无损压缩；板端与 Mac 共用 C 解码库。USB 实时通道仍发送原始帧，NCM/TCP 为兼容模式。IMU 同步、跨帧追踪、Mac 原生 GUI 和跨端控制仍属规划。

**基本约束：** 图像采集和传输为关键路径；GPU、NPU、深度估计与热点分析应异步执行。所有衍生结果必须关联原始帧编号及对应采样时间。预分析结果是可撤销的建议，不能取代原始图像。

## 2. 软件模块与计算职责

| 模块           | 平台                      | 职责                                      | 状态                          |
| -------------- | ------------------------- | ----------------------------------------- | ----------------------------- |
| 图像采集与缓冲 | RK3588 CPU / V4L2         | RAW10、序号/时间、曝光、帧率与有界队列 | 已接入主程序；录制缓冲上限 4 GiB |
| 边缘运动分析   | RK3588 CPU / Mali-G610    | 独立峰值预览、Vulkan 边缘与实时/离线放大 | 已接入触屏；Tile 热点扫描待扩展 |
| 场景感知       | RK3588 NPU / RKNN         | MobileSAM 点/框物品选择与蓝色掩膜 | 主程序实机通过；不输出类别，不做追踪 |
| 本机录像       | RK3588 CPU / eMMC        | Bitshuffle + LZ4、CRC、完整 END、原子发布 | 约 30 秒 120 FPS 档实拍通过；长期压力待验收 |
| IMU采集及对齐  | RK3588 / SPI              | 自振频谱、时间基准与同步                  | 规划中                        |
| 高速传输       | RK3588 ↔ MacBook          | VRI1 原始帧、时间戳、序号、CRC；USB Bulk | 原始流实机验收通过；压缩传输尚未实现 |
| 相位运动放大   | MacBook / Metal           | 时域滤波、金字塔、放大和重建              | 真实 Bulk 输入已验收，算法队列仍有替换 |
| 测量与可视化   | RK3588 Qt/QML / MacBook   | 触屏预览、频谱、区域/边缘及 RAW 时间区间 | 板端已集成；Mac 原生 GUI、时频图/热力图待开发 |

分块预分析保留原始像素尺寸时，仍应保证对应Tile的**时间采样连续性**。逐帧轮流切换Tile虽然不会降低相机采集FPS，却会降低该Tile的有效时间采样率；需要采用连续特征采样或缓存连续原始帧后异步分析。

## 3. RK3588 计算后端

板端接口与构建命令见 [五项后端](../../03-apps/rk3588/BACKENDS.md)。

1. GPU 峰值对焦：原图梯度、峰值掩膜、清晰度分数。
2. NPU 物品选择：MobileSAM 点/框交互分割，缓存 embedding，原图坐标掩膜。
3. GPU 物品边缘：在物体掩膜内部和边界窄带筛选强边缘，返回两侧测量区域及法线。
4. GPU 实时放大：固定 ROI、显式整数分频；严格检查处理预算、连续采样和输出。
5. GPU 离线放大：VRI1 逐帧完整处理，保持原始空间/时间采样；默认前后向零相位整段滤波，可显式选择因果滤波；磁盘暂存，Double时间递推。

这些接口保留为独立库/CLI，同时由 `vr-touch` 主程序调度采集、录制、传输、预览与计算线程。主程序提供启动前资源检查和运行中超限保护，不代表任意多任务组合均已完成持续负载验收。
预览和选物允许按需异步调用；连续测振不可沿用预览的丢旧帧策略。
掩膜限定选区，测量使用原始灰度，不能直接把分割轮廓当成精确位移。
实际调用端必须保留源帧身份，并在选区变动时重建时域处理实例。

## 4. macOS 后端模式

实现及调用方式见 [macOS 后端](../../03-apps/macos/README.md)。实时模式优先保留时间采样率，按处理耗时降低空间分辨率；异步队列最多保留一帧处理中、一帧待处理，替换待处理帧时明确计数，后续因序号间断重置滤波历史。离线模式通过磁盘暂存完整片段，默认前向—反向零相位滤波，再按序逐帧重建，保留原始或 ROI 分辨率及每一帧，不受实时性能预算限制；资源不足直接报错。可导出指定空间位置/金字塔层的局部相位幅度谱与 PSD，增益范围为 0～200。

两个模式使用原始采集时间与源 FPS，输出携带原始序号、时间、ROI、实际工作尺寸及滤波重置标记。Mac 后端不包括原生 GUI、相机驱动和通用视频容器编解码。`VibraRevealTransport` 负责 VRI1 接收与归档读取；CLI 支持 `--usb`、`--connect` 和 `--archive`，兼容原始及板端压缩录像，保留真实采集元数据。无头 RAW 输入仍使用合成时间。

## 5. 本机录制与离线分析

录制始终保存全幅 RAW，区域选择只决定分析范围。写盘线程对完整帧压缩，不改变采集序号、时间、位深或 padding；缓冲不足停止接收新帧，排空连续前缀后发布。写入失败保留 `.partial`，不得报告为成功录像。

蓝色为 NPU 物品掩膜，红色为候选/选中边缘及放大矩形。矩形支持拖动与八点缩放，可直接整区放大或进入边缘测量；整区模式不生成边缘位移频谱。RAW 默认从选取对象的帧分析，可指定时长或从当前帧直接全画面分析。仅区间内运行零相位滤波，但完整源录像仍验证 CRC、采样连续性和 END。
