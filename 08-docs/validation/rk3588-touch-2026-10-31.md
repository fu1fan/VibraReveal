# RK3588 触屏应用验证 · 2026-10-31

后续 SDK 和板端工作已完成，见 [2026-11-01 验证](rk3588-touch-2026-11-01.md)。以下保留当日结果。

## 版本与范围

新增 `vr-touch` Qt/QML 应用，连接已有相机、Vulkan、MobileSAM、离线处理及 RAW 传输后端。
CMake 要求 Qt 5.15.10 EXACT，并核对宿主 moc/rcc；程序启动时核对运行库版本。
板端 Qt 没有修改。源码与构建配置尚未提交、发布或部署。

## 已执行

- Linux/amd64、官方 Qt 5.15.10 源码构建，容器 `vibrareveal-qt51510-tests:local`。
  使用软件 Qt Quick/offscreen 和 Vulkan lavapipe，成功编译应用及可选 RKNN 选择代码。
- CTest：`vulkan-motion`、`vulkan-features`、`vulkan-offline`、`touch-core`、`touch-ui`
  **5/5 通过**，最后一轮总耗时 9.22 秒。
- 核心测试覆盖在途写盘内存预算、低内存停录、采集缺口、写盘异常、禁止覆盖已有文件、
  FFT 已知频率、小位移估计和 TCP 文件传输确认。
- UI 测试操作真实 QML 控件，覆盖 1:1 对焦锁定与恢复、坐标映射与拖动、录制期间限制、
  保存/回放/重新选对象与边缘、离线输出、实时频谱和电脑直通切换。
  合成 12 Hz 信号在离散频谱中检出约 11.95 Hz；这是合成测试，不是物理标定。
- 实际 macOS `vr-receive` 与新增录制/传输模块通过 loopback TCP 互通：
  100 帧、204800 字节，接收端零队列丢帧/序号缺口，接收文件重新读取成功。
  这不代表真实 USB 或相机带宽验收。
- 1024×600 原生界面截图检查覆盖对焦、录制、实时放大和离线结果。
- 开发环境回归：Linux 14/14 通过；macOS 14 项中 11 项通过、3 项因 Linux 工具要求跳过。
  shell 语法检查及 `git diff --check` 通过。
