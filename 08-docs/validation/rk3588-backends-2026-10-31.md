## GPU 与输入完整性

- `vr-motion-test` 在 llvmpipe 与 Mali-G610 均通过：非零增益64帧、alpha=0、奇数/细长ROI、padding、格式/时间/序号错误。
- 对独立 NumPy 相位参考最大绝对误差：llvmpipe `3.2492609e-6`，Mali `4.2778547e-6`；实时 CLI 二进制输出与阻塞输出截止时间回归通过。
- `vr-features-test` 在 llvmpipe 与 Mali-G610 均通过：平坦图+物体掩膜不制造边缘、清晰图分数高于模糊图、边缘区域位置、帧身份保留。
- 独立 NumPy Gaussian/Sobel 与 GPU 梯度结果误差小于 `1e-6`；llvmpipe 启用 Vulkan validation/synchronization validation 的 CTest 通过。
- `rk3588_backend.py` 通过：64帧离线与原相位实现数值一致、全帧alpha=0重建、CRC/缺失END/尾随数据拒绝、输出不覆盖、预览抽样和元数据。
- 旧 NCM 录像的累计替换计数非零，板端离线处理返回 `FRAME_DROPPED`，未发布完整结果。
- 完整性合格的 Bulk 录像截取16帧，保持原始1280×800、10-bit、120FPS元数据并重写截取片段END总数。
  Mali 上非零增益全帧离线处理完成，进程墙钟约0.900秒（含初始化/读写）；输出16个1280×800 float32帧，逐帧头和长度检查通过。
  这不是持续实时吞吐承诺，也不是物理测量精度验证。
- 同片段全分辨率特征分析每16帧取1帧，输出峰值/边缘/区域及完成元数据，进程墙钟约0.416秒。

## NPU 与串联

输入使用 Rockchip Model Zoo MobileSAM 示例 `picture.jpg` 转灰度，769×770。
来源：https://github.com/airockchip/rknn_model_zoo/blob/main/examples/mobilesam/model/picture.jpg

- 实际 RK3588 NPU 完成 encoder 和 decoder，无应用层 CPU 模拟推理回退。
- 框提示 `(190,70)-(460,280)` 选中上方吉他形招牌；另一轮使用正点 `(370,210)` 和负点 `(520,350)`。
- `vr-selection-test` 通过：缓存 embedding 后重复框提示掩膜一致、正负点输入、帧身份、越界/无正点/倒置框/容量错误、新图无效后旧缓存失效。
- 一次测量：图像预处理+encoder约118.377ms；提示处理+decoder+还原掩膜约29.557ms。
