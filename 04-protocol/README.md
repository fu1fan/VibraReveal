# 04-protocol · 通信协议

定义 RK3588 与 MacBook 之间的数据格式与交互约定。

## 计划覆盖

| 内容     | 说明                                             |
| -------- | ------------------------------------------------ |
| RAW 图像 | 帧头、分辨率、位深、帧序号、曝光与采样时间       |
| IMU      | 六轴采样、量程、时间戳与视觉时钟域对齐           |
| ROI      | 选区下发、跟踪结果回传、坐标与缩放约定           |
| 控制     | 参数设置、状态上报、错误码                       |
| 版本     | 协议版本号与向后兼容规则                         |
