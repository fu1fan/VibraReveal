测试覆盖：

- 奇数宽高、1×1、单像素轴的零增益重建；误差阈值 3e-6。
- RAW10 的有效位、padding stride、ROI 像素对应关系。
- 输入、ROI、频带和 Float32 稳定性校验；配置失败保留原配置。
- 序号缺口、时间跳变、尺寸及位深改变时重置历史。
- 静止图像与全黑输入稳定；棋盘格空间降采样。
- 实时内存/像素预算，极细 ROI 像素上限，自适应降级与最低尺寸；冷启动不触发误降级。
- 阻塞消费者后连续提交 100 帧：只保留最新待处理帧，明确计数 99 帧替换，排空后输出序号 0、100。
- 离线模式在 0.25、59.94、10,000 FPS 的有效频带下保持完整尺寸，忽略实时预算；这是时间基准支持测试，不代表达到 10,000 FPS 吞吐。
- CLI 实时二进制帧边界、元数据、灰度值及最新帧；离线 50 帧全部按序输出、尺寸不变；残缺帧和非法参数报错。

合成正弦纹理位移 0.08 像素、alpha=5、120 FPS、频带 5–12 Hz、360 帧，统计末 120 帧相对零增益输出的附加信号 RMS：

| 频率 | 附加信号 RMS |
| --- | ---: |
| 0.5 Hz | 0.000712 |
| 8 Hz | 0.011793 |
| 40 Hz | 0.001321 |

该检查表明带内响应强于选定带外信号；不等同于真实位移放大倍率标定，也不证明所有场景画质。

## 零相位与频谱扩展验证

- 允许 alpha=200，拒绝 >200；实时拒绝零相位请求，逐帧接口不静默回退到因果滤波。
- 200 增益下静止 RAW10 + ROI 保持恒等，移动纹理下输出为有限值。
- 120 FPS / 10 Hz 微位移合成序列，测量内部稳态输出附加信号的正交/同相信号比 <0.03，验证零相位响应；原始和滤波后探针谱均定位 10 Hz。
- 128 FPS 的 1、8、48 Hz 混合微位移，5–12 Hz 带通后 8 Hz 幅度比 >0.9，1/48 Hz 均 <0.05。
- FFT 与独立直接 DFT 对照（奇数观测长度）；0.25 rad 正弦幅度、PSD 积分、Nyquist 单边归一化、零信号与非法样本检查通过。
- 离线断序、过短片段和 sink 抛错检查通过，正常/失败路径的临时目录清理通过。
- CLI：256 帧 RAW16、128 FPS、8 Hz 微位移、alpha=200，完整输出并成功生成 JSON 频谱，原始和滤波后主峰均为 8 Hz；因果选项和非法参数检查通过。

当前 Release 全流程测量：

```bash
vibrareveal benchmark --mode offline --width 321 --height 241 --fps 120 --frames 120 --alpha 200
```

Apple M5 上完整零相位任务耗时约 **0.498 s**；原尺寸 321×241，120 帧全部处理，每端延拓 119 帧。计时包含合成输入生成、磁盘暂存、两遍滤波和重建，benchmark 输出消费者为空，不含视频编码或文件输出。该短片测量不能推断长片的稳态速度。

## 首版因果基线 Release 测量（历史）

以下记录来自加入零相位前的首版，用于保留历史证据，不能作为当前离线完整流程的性能结果。命令均使用默认 alpha=10、三层、频带 3–12 Hz；实时模式初始最大 1,048,576 工作像素。每组顺序独立执行。

```bash
vibrareveal benchmark --width 1280 --height 800 --fps 120 --frames 180
vibrareveal benchmark --width 1921 --height 1081 --fps 240 --frames 120
vibrareveal benchmark --mode offline --width 1921 --height 1081 --fps 240 --frames 120
```

| 模式 | 源分辨率 / FPS | 帧数 | 最终处理尺寸 | 单帧中位数 | P95 | 最终状态 |
| --- | --- | ---: | --- | ---: | ---: | --- |
| 实时 | 1280×800 / 120 | 180 | 1280×800 | 2.233 ms | 2.699 ms | sustainable |
| 实时 | 1921×1081 / 240 | 120 | 1365×768 | 2.400 ms | 2.770 ms | sustainable |
| 离线 | 1921×1081 / 240 | 120 | 1921×1081 | 4.076 ms | 7.346 ms | offline |

耗时包含输入上传、GPU 计算、等待和 Float32 读回，排除合成图像生成、传输、视频编解码及结果消费。初始化 Metal shader 编译在计时前完成；首帧缓冲区分配在帧耗时内。源 FPS 决定滤波时间基准，benchmark 本身不模拟真实到达节奏。结果受其他系统负载影响，不是持续实时吞吐保证。

## 已知边界

- 未接入真实全局快门相机、AVFoundation 或 RK3588 网络输入；未验收长时运行、功耗、热降频和采集到输出延迟。
- 离线默认零相位，整段 FFT 目前用于频谱分析而非视频时间滤波；真实可变帧率需预处理时间轴。局部相位频谱不等于物理位移标定或全图热力图。
- macOS 13 为声明的最低部署版本，本次只在当前本机系统执行，未验证所有 macOS/Intel GPU 组合。
- 本地工作目录的 XCTest 签名遇到 Finder 扩展属性错误，改用 `/tmp` scratch path 后成功；未修改用户原有文件的扩展属性。
