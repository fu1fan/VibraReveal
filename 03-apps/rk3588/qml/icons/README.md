# Touch UI icons

Lucide Static 0.468.0, from https://registry.npmjs.org/lucide-static/-/lucide-static-0.468.0.tgz. ISC license, including Feather-derived portions; see LICENSE.

These are the 17 Lucide icons used by the approved rk3588-touch HTML prototype. Only `currentColor` is replaced with explicit product colors (dark, light, accent, recording, success). SVG geometry is unchanged. All variants and the license are embedded in the Qt resource, so the board works offline using its existing Qt 5.15.10 SVG image plugin.

Mappings: scan-line/monitor = local/direct; sliders-horizontal = settings; focus/scan/activity/circle-dot/folder-open = bottom tools; x = close; chevron-right = frequency settings; square = stop recording; chart-no-axes-combined/send = file analysis/transfer; play/pause = playback; circle-check/unplug = computer connection state.
