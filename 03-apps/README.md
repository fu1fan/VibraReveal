# 03-apps · 平台应用

本目录归档 VibraReveal 的两个端侧应用：RK3588 采集/预分析应用与 Mac 端分析/可视化应用。两端各自独立构建、独立发布，通过 [05-protocol](../05-protocol/README.md) 定义的协议对接。

## 子目录

| 子目录                | 平台                   | 职责                                                     | 状态         |
| --------------------- | ---------------------- | -------------------------------------------------------- | ------------ |
| [rk3588](rk3588/)     | ELF 2 · RK3588 Linux   | V4L2 采集 OV9281 RAW10、帧缓冲与异步队列、Vulkan 预分析、RKNN 检测与 ROI、IMU 对齐、高速传输与控制 | 目录占位，无代码 |
| [macos](macos/)       | Apple Silicon · macOS  | 接收 RAW 与元数据、Metal 相位运动放大、频谱/时频分析、交互选区与结果导出 | 目录占位，无代码 |
