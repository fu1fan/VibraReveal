# 03-apps · 平台应用

本目录归档 VibraReveal 的两个端侧应用：RK3588 采集/预分析应用与 Mac 端分析/可视化应用。两端各自独立构建、独立发布，通过 [05-protocol](../05-protocol/README.md) 定义的协议对接。

## 子目录

| 子目录                | 平台                   | 职责                                                     | 状态         |
| --------------------- | ---------------------- | -------------------------------------------------------- | ------------ |
| [rk3588](rk3588/)     | ELF 2 · RK3588 Linux   | Qt 5.15.10 触屏测量、相机控制、Vulkan 放大/边缘、RKNN 选物、RAW 无损录制与 USB Bulk | 已部署原板；[操作指南](rk3588/TOUCH_APP.md) |
| [macos](macos/)       | Apple Silicon · macOS  | VRI1 接收、原始/压缩归档读取、Metal 实时/离线放大与局部相位频谱 | 库与 CLI 已实现；原生 GUI 待开发 |
| [raw-codec](raw-codec/) | 共享 C 库 | Bitshuffle + LZ4 fast8，每帧无损编码、解码与原始帧回退 | 两端静态链接；原板/Mac 校验通过 |

板端主程序以本机流程为主；电脑直通仅传原始 RAW，由电脑决定录制或处理。对象选择、峰值对焦及本机放大叠加不与电脑同步。IMU 对齐、跨帧追踪、跨端控制及传输压缩仍属规划，不能由后端能力推定已完成。

实现与验证入口：[触屏应用](rk3588/TOUCH_APP.md)、[板端记录](../08-docs/validation/rk3588-touch-2026-11-01.md)、[协议](../05-protocol/README.md)、[测试指南](../06-tests/README.md)。
