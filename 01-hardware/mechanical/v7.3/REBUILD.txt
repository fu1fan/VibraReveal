VibraReveal V7.3 / mm / engineering prototype, not fabrication release.

CAD and QA (run from this directory; use an isolated copy because build.py replaces generated STEP/STL/DXF):
  Python 3.12 with compatible cadquery / ezdxf
  python build.py
  python verify_all_assembly.py
  python verify_geometry.py
  python verify_service.py
  python check_relay_service_final.py
  python export_film_template.py
Parameters live in build.py; parameters.json is a snapshot, not a loaded configuration.
The two source STEP files under sources/ are required. The former isolated rebuild evidence is retained; this document-only release did not rerun or change CAD geometry.

CAD rendering:
  Python Pillow and Blender 4.x; follow render_cad.py, annotate_views.py, make_imu_view.py, annotate_imu.py.
  Some annotation font paths require a local Noto Sans CJK installation.
  The final original PNGs are already under renders/.

Readable assembly PDF (Python reportlab / PyMuPDF / ezdxf / Pillow):
  python docs/make_pdf_readable.py
Uses relative docs/readable_assets and renders paths. Generates an intermediate body.pdf locally; do not treat that as an additional final deliverable.

Full BOM PDF (Python reportlab):
  python bom/make_bom_pdf.py
Uses bom/bom_data.json and ReportLab's STSong-Light CID font.

Full BOM workbook:
  bom/build_bom_workbook.mjs uses the @oai/artifact-tool runtime used for authoring.
  Run using a runtime providing that package, with optional output-directory argument.
  No private credentials are required. JSON and UTF-8 CSV remain editable without this runtime.

Manufacturing: only A*.dxf laser parts, P*.stl printed parts, and separate film template. REF/hardware/presentation geometry is not manufacturing output. Review README.md, BOM confirmation status and 说明_先读.md first.
