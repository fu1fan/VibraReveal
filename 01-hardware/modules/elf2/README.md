# elf2 · ELF 2（RK3588）开发板

ELF 2 是飞凌嵌入式（elfboard）面向嵌入式 AI 与教学实验的 **RK3588** 开发板，在 VibraReveal 中担任**边缘计算与采集控制平台**：通过 MIPI CSI-2 接入 OV9281，完成高帧率 RAW 采集、帧编号/时间戳打标，并在板内做 Vulkan Compute 局部运动预分析与热点扫描，再把数据推送到 MacBook 做相位运动放大。

选型关注点是 RK3588 的 VPU/ISP 吞吐、Vulkan 计算能力和可用 NPU：采集链路必须与显示、网络隔离，预分析不得反压相机。

## 1. 规格概览

| 项目 | 参数 |
| ---- | ---- |
| 主控 | Rockchip RK3588 |
| CPU | 4 × Cortex-A76 + 4 × Cortex-A55，最高 2.4 GHz |
| NPU | 6 TOPS |
| 系统 | Linux 5.10；桌面版 Elf2 Desktop 22.04（厂商提供） |
| 本项目用途 | 相机采集、RAW 转发、Vulkan 预分析、设备侧交互 |

## 3. 在项目中的角色

- **采集主控：** 负责 OV9281 的 `1280 × 800 @ 120 FPS` RAW10 采集与帧标记，是"保留原始时间分辨率"的第一道关口。
- **板内预分析：** 已调通 Vulkan 运行环境，后续承载局部运动特征、振动热点搜索与 ROI 跟踪；NPU 用于目标识别。
- **系统归属：** 内核、设备树、OV9281 驱动、Buildroot 与系统镜像由独立仓库 [RK3588-OV9281](https://cnb.cool/fu1fan/RK3588-OV9281) 维护，并以子模块挂载在 [02-platform](../../../02-platform)，本目录**只归档厂商资料**，不放置系统源码。
- **配套外设：** HDMI 输出接 [7inch\_HDMI\_LCD\_C](../7inch_HDMI_LCD_C) 做本地界面，USB/网络负责与 MacBook 的数据通道。
