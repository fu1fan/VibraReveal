# ov9281 · 全局快门灰度相机模组

OmniVision **OV9281** 是 VibraReveal 的成像前端：1/4 英寸、100 万像素级、**全局快门（Global Shutter）** 黑白传感器，适合高帧率、低运动畸变的微小位移采集。本项目使用 15P FPC 排线的商用摄像头模组，经 MIPI CSI-2 接入 ELF 2（RK3588）开发板。

选择该传感器的原因是运动放大对时间分辨率与帧间一致性极敏感：卷帘快门的逐行曝光会在高帧率下引入空间畸变，而全局快门保证整帧同时曝光，帧间差分更接近真实运动。

## 3. 在项目中的角色

- **采集前端：** 目标是以 `1280 × 800 @ 120 FPS`、RAW10 灰度输出，并尽可能保留帧编号与曝光信息，供 MacBook 端做相位运动放大与频谱分析。
- **驱动归属：** 内核驱动、设备树与系统镜像由 [RK3588-OV9281](https://cnb.cool/fu1fan/RK3588-OV9281) 独立仓库维护，本目录只归档器件资料，不含驱动代码。
- **结构约束：** 模组尺寸与镜头后焦决定相机支架设计，机械部分见 [01-hardware/mechanical](../../mechanical/README.md)（待建）。
