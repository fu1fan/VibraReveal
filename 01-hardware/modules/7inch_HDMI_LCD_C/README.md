# 7inch_HDMI_LCD_C · 7 寸 HDMI 显示模组

Waveshare（微雪）**7inch HDMI LCD (C)**：7.0 英寸 IPS 屏，1024 × 600 硬件分辨率，显示走标准 HDMI，供电与触摸共用一路 Micro USB，5 点电容触控。在 VibraReveal 中用作 ELF 2（RK3588）的本地监视与交互面板——显示取景画面、ROI 框选、振动频谱与参数配置界面。

该屏只有 60 Hz 刷新率，仅承担"看"和"操作"的职责，**不进入高速采集链路**，也不作为帧同步或时间基准参考。

## 3. 使用注意

- **HID 免驱：** REV2.1 起采用标准 HID 协议，Linux/Windows 下多点触摸免驱；仅 REV4.1 支持 USB 调光。若触摸不可用，先确认设备是否被识别为 HID 多点触摸设备，并核对实物版本号（REV1.1 为私有协议，Linux 需装驱动）。
- **供电余量：** Micro USB 电流不足 500 mA 会出现启动失败或显示异常，建议独立供电或使用带外部供电的 USB Hub，避免与相机、调试串口抢电。
- **仅 60 Hz：** 预览画面必然低于相机 120 FPS 的采集帧率，界面上显示的帧号/时间戳必须来自采集端数据，而不是屏幕刷新时刻。
- **结构件命名：** `1118` 为厂商内部件号，与屏幕 SKU（11199 无外壳 / 11284 带外壳）不同，装配时注意区分。
